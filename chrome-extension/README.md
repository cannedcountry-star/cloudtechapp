# CloudTech Chrome拡張機能 (Quick Access)

Google Chromeのツールバーから、ワンクリックでCloudTechの各コース・講義へアクセスできる拡張機能です。

## インストール手順

1. Google Chrome を開きます。
2. アドレスバーに `chrome://extensions/` と入力して Enter を押します。
3. 画面右上の **「デベロッパーモード」** スイッチを **ON** にします。
4. 画面左上に表示される **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
5. この `chrome-extension` フォルダを選択します。
6. Chromeのツールバー右上（パズルピースのアイコン）から「CloudTech Quick Access」をピン留めすると、いつでもワンクリックでアクセスできるようになります！
