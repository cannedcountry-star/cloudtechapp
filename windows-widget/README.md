# CloudTech Windows デスクトップ ウィジェット

Windows 10 / 11 のデスクトップ上に常駐できる、CloudTech専用のクイックアクセスウィジェットです。

## 主な機能

- 🖥️ **フローティングウィジェット**: デスクトップの好きな場所にドラッグ＆ドロップで配置できます。
- 📌 **最前面ピン留め機能**: ヘッダーの「📌」をクリックすることで、最前面表示と通常表示を切り替えられます。
- 🔔 **タスクトレイ常駐**: ヘッダーの「―」をクリックすると画面右下のタスクトレイ（通知領域）に格納されます。トレイアイコンのダブルクリックでいつでも呼び出せます。
- 🌐 **Chrome / 既定ブラウザで即座に開く**: 各カードをクリックすると、Windowsの既定ブラウザ（Google Chrome等）が立ち上がり、直接学習ページが開きます。
- 🪶 **軽量スタンドアロン**: インストーラーや追加のランタイム不要で、`CloudTechWidget.exe`（約12KB）をダブルクリックするだけで動きます。

## 起動方法

`CloudTechWidget.exe` をダブルクリックするだけです。
（※デスクトップやスタートメニュー、タスクバーにショートカットを作成しておくと便利です）

## ソースコードからの再ビルド方法

`build.bat` を実行するだけで、Windows標準のC#コンパイラ（`csc.exe`）により即座にビルドされます。
